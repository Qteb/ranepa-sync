# Расписание РАНХиГС

Неофициальное мобильное приложение с расписанием занятий для студентов РАНХиГС.
Расписание берётся из личного кабинета студента (my.ranepa.ru).

> Приложение не связано с РАНХиГС и не поддерживается академией.

## Что умеет

- Показывает расписание твоей группы и подгрупп: сверху карточка с текущей или
  следующей парой, ниже — пары дня с перерывами между ними.
- Работает без интернета: расписание на 5 недель хранится на телефоне.
- Обновляется в фоне и присылает уведомление, если пару перенесли, отменили,
  добавили или поменяли аудиторию.
- Напоминает о паре заранее.
- Выгружает пары в отдельный календарь «РАНХиГС» на телефоне.
- Показывает ближайшие пары в виджете на главном экране и экране блокировки.

## Приватность

Логин и пароль вводятся на настоящей странице личного кабинета, открытой внутри
приложения, и уходят только на сайт академии. У приложения нет своих серверов,
аналитики и трекинга: всё хранится на телефоне.
Подробнее — в [политике конфиденциальности](PRIVACY.md).

## Как это устроено

- **Вход.** Студент логинится на странице ЛК во встроенном WebView
  (`flutter_inappwebview`). Приложение не видит и не хранит логин и пароль.
- **Данные.** Сайт закрыт JS-проверкой браузера, поэтому все запросы идут изнутри
  WebView. Приложение перехватывает запрос расписания, который делает сама
  страница (`n-api/schedule` с `uid_org` и всеми группами студента), и по нему
  скачивает 5 недель через `fetch` с Bearer-токеном из localStorage
  (`lib/ranepa_client.dart`).
- **Обновление.** Скрытый `HeadlessInAppWebView` открывает ЛК с сохранёнными
  cookie и токенами, страница сама обновляет токен. Обновление запускается при
  открытии приложения, если данные старше 4 часов, жестом «потянуть вниз» и в
  фоне.
- **Нагрузка на ЛК.** Месяц вперёд (5 недель) грузится при входе и первым
  обновлением за день, остальные обновления берут только текущую неделю
  (с пятницы — и следующую). Фон не ходит в ЛК с 00:00 до 07:00, а по
  воскресеньям и на каникулах делает только ежедневную загрузку. Ответ
  429/5xx ставит все обновления на паузу 8 → 16 → 24 часа (или по
  `Retry-After`). Ручное обновление не чаще раза в 2 минуты.
- **Удалённый конфиг.** Раз в сутки приложение читает `config.json` из ветки
  [`config`](https://github.com/Qteb/ranepa-sync/tree/config) (GitHub,
  запасной адрес — jsDelivr). Через него можно остановить обращения к ЛК
  или сделать их реже без новой сборки (`lib/services/remote_config.dart`).
- **Фон.** `workmanager`: на Android — WorkManager раз в 3:50–4:10 при наличии сети,
  на iOS — `BGAppRefreshTask`, время запуска выбирает система. Access-токен ЛК
  живёт час, refresh-токен — сутки и выдаётся заново при каждом обновлении,
  поэтому пока фоновое обновление работает, повторно входить не нужно
  (`lib/services/background.dart`, `lib/services/sync.dart`).
- **Изменения.** Новое расписание сравнивается с сохранённым; изменения в
  ближайшие 7 дней приходят одним уведомлением (`lib/services/changes.dart`).
  Если приложение не обновлялось 20 часов (например, его смахнули из памяти),
  приходит напоминание открыть его до того, как истечёт сессия.
- **Календарь.** `eventide` ведёт отдельный календарь «РАНХиГС» и пересоздаёт
  события при каждом обновлении.
- **Виджет.** `home_widget` передаёт пары на 14 дней через App Group. Нативный
  виджет (iOS — `ios/RanepaWidget`, Android — `RanepaWidgetProvider.kt`) сам
  отбрасывает прошедшие пары.
- **Интерфейс.** Экраны свёрстаны на Cupertino-виджетах по Apple Human Interface
  Guidelines.

## Сборка

Нужны Flutter 3.47+, Xcode и CocoaPods (для iOS) или Android Studio (для Android).

```bash
flutter pub get
flutter run                      # на подключённом устройстве или симуляторе
flutter build ios --simulator    # сборка для iOS Simulator
flutter build apk                # APK для Android
```

В отладочной сборке на экране аккаунта есть раздел «Отладка»: запуск фонового
обновления и имитация изменения в расписании. В релизную сборку он не попадает.

### Своя сборка для iPhone

Идентификаторы в проекте привязаны к аккаунту разработчика автора. Чтобы собрать
приложение под своим аккаунтом Apple, замени их на свои:

| Что | Где |
|---|---|
| Команда разработчика (`DEVELOPMENT_TEAM`) | `ios/Runner.xcodeproj/project.pbxproj` или Xcode → Signing & Capabilities у таргетов `Runner` и `RanepaWidgetExtension` |
| Bundle ID `com.qteb.ranepaTimetable` | `ios/Runner.xcodeproj/project.pbxproj` |
| App Group `group.com.qteb.ranepatimetable` | `ios/Runner/Runner.entitlements`, `ios/RanepaWidget/RanepaWidget.entitlements`, `ios/RanepaWidget/RanepaWidget.swift`, `lib/services/home_widget_bridge.dart` |
| Удалённый конфиг `Qteb/ranepa-sync@config` | `lib/services/remote_config.dart` |
| Фоновая задача `com.qteb.ranepaTimetable.refresh` | `ios/Runner/Info.plist`, `ios/Runner/AppDelegate.swift`, `lib/services/background.dart` |
| Android `applicationId` `com.qteb.ranepa_sync` | `android/app/build.gradle.kts`, пакет Kotlin в `android/app/src/main/kotlin/com/qteb/ranepa_sync` |
