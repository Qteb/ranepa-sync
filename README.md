# Расписание РАНХиГС (Flutter)

Мобильное приложение для iOS и Android: показывает расписание из личного кабинета
my.ranepa.ru, напоминает о парах, выгружает их в календарь телефона и показывает
ближайшие пары в виджете.

## Как это устроено

- **Вход.** Студент логинится на настоящей странице ЛК во встроенном WebView.
  Пароль приложение не видит и не хранит.
- **Данные.** Сайт закрыт JS-проверкой браузера, поэтому все запросы идут изнутри
  WebView. Сначала перехватывается запрос расписания, который делает сама страница
  (`n-api/schedule` с `uid_org` и всеми группами студента). Затем по нему
  скачиваются 5 недель через `fetch` с Bearer-токеном из localStorage.
- **Обновление.** Скрытый `HeadlessInAppWebView` открывает ЛК с сохранёнными
  cookie и токенами, страница сама обновляет токен. Обновление запускается при
  открытии приложения, если данные старше 3 часов, или жестом «потянуть вниз».
- **Хранение.** Сырые данные кэшируются в `shared_preferences`, так что приложение
  работает офлайн.
- **Напоминания.** `flutter_local_notifications`, до 60 штук вперёд (лимит iOS — 64).
- **Календарь.** `eventide` ведёт отдельный календарь «РАНХиГС». При каждом
  обновлении события в диапазоне пересоздаются.
- **Виджет.** `home_widget` передаёт пары на 14 дней через App Group
  `group.com.qteb.ranepatimetable`. Нативный виджет (iOS — `ios/RanepaWidget`,
  Android — `RanepaWidgetProvider.kt`) сам отбрасывает прошедшие пары.

## Сборка

Нужны Flutter 3.47+, Xcode и CocoaPods (для iOS) или Android Studio (для Android).

```bash
flutter pub get
flutter run                      # на подключённом устройстве или симуляторе
flutter build ios --simulator    # сборка для iOS Simulator
flutter build apk                # APK для Android
```

Для установки на настоящий iPhone в Xcode нужно выбрать команду разработчика
(Signing & Capabilities) у таргетов `Runner` и `RanepaWidgetExtension`.
App Group должна быть зарегистрирована на эту команду.
